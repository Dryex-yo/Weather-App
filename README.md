# 🌤️ WeatherSky Pro

WeatherSky Pro adalah aplikasi prakiraan cuaca modern yang dibangun menggunakan Vanilla JavaScript dan Visual Crossing API. Aplikasi ini menampilkan data cuaca real-time dengan tema visual yang berubah sesuai kondisi cuaca.

## ✨ Fitur Utama
- **Real-time Search**: Cari cuaca di kota mana pun di dunia.
- **Dynamic Background**: Latar belakang aplikasi berubah otomatis (Cerah, Hujan, Berawan, Salju).
- **Unit Toggle**: Pindah antara Celsius dan Fahrenheit dengan mudah.
- **Responsive Design**: Tampilan optimal di perangkat desktop maupun mobile.
- **Modern UI**: Menggunakan Glassmorphism dan animasi fade-in yang halus.

## 🚀 Tech Stack
- **Frontend**: Vanilla JavaScript (ES6 Modules)
- **Styling**: CSS3 (Flexbox, Grid, Keyframe Animations)
- **API**: [Visual Crossing Weather API](https://www.visualcrossing.com/)
- **Icons**: SVG Weather Icons

## 🛠️ Cara Menjalankan Secara Lokal
1. Clone repository ini.
2. Buka file `dist/index.html` menggunakan **Live Server** di VS Code.
3. Masukkan API Key kamu di file `src/api.js`.
